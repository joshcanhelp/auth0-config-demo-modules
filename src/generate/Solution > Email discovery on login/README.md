# Email Discovery Page

This needs a bit more description but this solution calls a public API with an email address to determine whether that email exists in Auth0 and/or an MDM, then redirects to login or signup based on that decision.

More details here:
https://app.notion.com/p/Email-Discovery-page-3ae81a33750480a7ad11e602f7333c49

This needs an API to be deployed and callable by the browser.
